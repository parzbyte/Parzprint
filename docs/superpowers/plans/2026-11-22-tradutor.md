# Tradutor: plano de implementação

> **Para quem executa:** use superpowers:subagent-driven-development (recomendado) ou superpowers:executing-plans, tarefa por tarefa. Os passos usam caixas (`- [ ]`) para acompanhar.

**Objetivo:** traduzir texto pelo Google Tradutor gratuito sem sair do que se está fazendo: atalho próprio sobre o texto selecionado, botão no OCR, botão "Traduzir a imagem" na captura, item na bandeja e `--translate`.

**Arquitetura:** pacote novo `parzprint/translate/` com quatro peças independentes: `google.py` (pedido e resposta, com `QNetworkAccessManager`), `languages.py` (lista e ordem dos idiomas), `grab.py` (pegar o texto selecionado ou copiado) e `window.py` (a janela). `app.py`, `editor.py`, `toolbar.py`, `textpanel.py`, `tray.py`, `single_instance.py`, `settings.py` e `settings_window.py` só ligam essas peças. Nada do tradutor é criado antes do primeiro uso.

**Tecnologia:** Python 3.12, PySide6 (QtNetwork, QtWidgets), ctypes no Windows, pytest com QApplication offscreen.

**Desenho:** `docs/superpowers/specs/2026-11-22-tradutor-design.md`. Leia junto com este plano.

## Regras gerais

- Nenhuma dependência nova. Rede só por `QNetworkAccessManager`.
- Endereço: `https://translate.googleapis.com/translate_a/single?client=gtx&sl=<origem>&tl=<destino>&dt=t`, texto no corpo de um POST (`q=<texto>`, `application/x-www-form-urlencoded`).
- Tempo máximo por pedido: 8000 ms. Limite de texto: 5000 caracteres.
- Atalho padrão: `Ctrl+Alt+T` no Windows e `Ctrl+Alt+Y` nos outros sistemas.
- Textos de tela em português, sem travessão. Cores da marca vêm de `parzprint/brand.py`.
- Commits sem assinatura de ferramenta, com o e-mail `347075219+parzbyte@users.noreply.github.com` que o repositório já usa.
- Nenhum teste acessa a internet.
- Texto que já estava copiado nunca vai ao Google sem Enter ou clique em Traduzir.

## Pontos de atenção para a revisão

1. **Resposta do Google sem tradução** (texto só com espaços, ou `[[null]]`): mostra resultado vazio, sem erro de formato. O teste fica na Tarefa 1.
2. **Texto com mais de 5000 caracteres colado na janela:** traduz os primeiros 5000 e mostra "Traduzi só os primeiros 5.000 caracteres." O teste fica na Tarefa 4.
3. **Atalho apertado com a janela já aberta:** reaproveita a mesma janela com o texto novo, sem abrir outra. O teste fica na Tarefa 4.
4. **Fechar o app no meio de um pedido:** o pedido é cancelado e nada é emitido para uma janela destruída. O teste fica na Tarefa 1 (`shutdown()`).
5. **Seleção com quebras de linha do Windows (`\r\n`) e caracteres fora do BMP (emoji):** chegam inteiros ao campo de origem. O teste fica na Tarefa 3.

**Arquivos:**

**Interfaces:**
- Produz:
  - `MAX_CHARS = 5000`, `TIMEOUT_MS = 8000`, `BASE_URL = "https://translate.googleapis.com/translate_a/single"`
  - `@dataclass(frozen=True) class Result: text: str; detected: str | None`
  - `class TranslateError(Exception)` com `kind: str`, um de `"network"`, `"refused"` ou `"format"`
  - `clip(text: str) -> tuple[str, bool]`: corta em `MAX_CHARS` e diz se cortou
  - `request_parts(text: str, source: str, target: str, base_url: str = BASE_URL) -> tuple[QUrl, bytes]`
  - `parse(raw: bytes) -> Result`: junta `data[0][i][0]` e lê `data[2]` como idioma detectado. Lança `TranslateError("format")` se a estrutura não bater.
  - `web_url(text: str, source: str, target: str) -> str`: `https://translate.google.com/?sl=..&tl=..&text=..&op=translate`
  - `class GoogleTranslator(QObject)`:
    - sinais `finished = Signal(int, object)` (id do pedido, `Result`) e `failed = Signal(int, str)` (id, kind);
    - métodos `translate(text, source, target) -> int`, que cancela o anterior e devolve o id, e `shutdown()`;
    - construtor `__init__(self, base_url: str = BASE_URL, timeout_ms: int = TIMEOUT_MS, parent=None)`.
  - Mapa de erros: falha de conexão ou tempo esgotado vira `"network"`; HTTP 429 ou outro status ≥ 400 vira `"refused"`; JSON inválido ou fora da estrutura vira `"format"`.

### Task 3: Pegar o texto

**Arquivos:**
- Criar: `parzprint/translate/grab.py`
- Teste: `tests/test_translate_grab.py`

**Interfaces:**
- Produz:
  - `@dataclass(frozen=True) class Grabbed: text: str; source: str`, com `source` sendo `"selection"`, `"clipboard"` ou `"none"`
  - `class Backend(Protocol)`:
    - `sequence() -> int`
    - `send_copy() -> None`
    - `wait_modifiers_released(timeout_s: float) -> None`
    - `read_text() -> str`
    - `read_primary() -> str | None`, onde `None` quer dizer que o sistema não tem seleção primária
  - `grab(backend: Backend, grab_selection: bool, wait_s: float = 0.3, poll_s: float = 0.02) -> Grabbed`. A ordem é:
    1. Se `grab_selection` estiver ligado e `read_primary()` devolver texto não vazio, devolve `"selection"`.
    2. Se `grab_selection` estiver ligado e `read_primary()` devolver `None`: espera as teclas serem soltas (0,5 s), guarda `sequence()`, chama `send_copy()` e consulta `sequence()` até `wait_s`. Se a sequência mudou e `read_text()` não estiver vazio, devolve `"selection"`.
    3. Se `read_text()` não estiver vazio, devolve `"clipboard"`.
    4. Se nada deu certo, devolve `"none"`.
  - `class WinBackend`: ctypes, com `GetClipboardSequenceNumber`, `SendInput` (Ctrl soltar e apertar, C, depois soltar), `GetAsyncKeyState` para Ctrl, Alt, Shift e Win, e `OpenClipboard`/`GetClipboardData(CF_UNICODETEXT)` com novas tentativas por até 100 ms se o clipboard estiver ocupado. `read_primary()` devolve `None`. Pode rodar fora da thread da interface.
  - `class QtBackend`: `QGuiApplication.clipboard()`. `read_primary()` usa o modo `Selection` quando `supportsSelection()` e, se não houver, devolve `None`. `send_copy` não faz nada. Só na thread da interface.
  - `default_backend() -> Backend`: `WinBackend` no Windows e `QtBackend` nos outros.
